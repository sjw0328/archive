## Warning / 주의

Some projects change system settings (audio output device, process priority, etc.) or access a webcam or a USB-connected phone.
Read the source before running, and use at your own risk.

일부 프로젝트는 시스템 설정(오디오 출력 장치, 프로세스 우선순위 등)을 바꾸거나 웹캠·USB 연결 휴대폰에 접근합니다.
실행 전 소스를 확인하고, 사용에 따른 책임은 사용자에게 있습니다.
